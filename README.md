# PM2.5 Data Preprocessing and Analysis

## Project Overview
This project focuses on data preprocessing and exploratory data analysis (EDA) of hourly PM2.5 concentrations in DKI Jakarta, Indonesia. The analysis aims to prepare the dataset for further statistical analysis and machine learning modeling.

## Dataset
The dataset covers hourly observations from January 2022 to December 2024 across air quality monitoring stations in DKI Jakarta (Bundaran HI, Kelapa Gading, Jagakarsa, Lubang Buaya, and Kebon Jeruk).

The data includes:
- PM2.5 concentration as the target variable
- Other air pollutants, including PM10, SO2, CO, O3, and NO2
- Meteorological variables, including temperature, rainfall, relative humidity, wind speed, Dew Point Temperature, and solar radiation

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Preprocessing
The preprocessing steps include:
1. Loading and combining datasets.
2. Converting date and time columns into the appropriate format.
3. Checking missing values and data types.
4. Handling missing observations.
5. Preparing the dataset for exploratory analysis and modeling.

## Exploratory Data Analysis
Exploratory analysis is conducted to understand the characteristics and distribution of PM2.5 concentrations through descriptive statistics and data visualizations.

This notebook covers the data preparation and initial analysis stages. Further work includes time series modeling, machine learning, and model performance evaluation.
